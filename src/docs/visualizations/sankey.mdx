### When to use

Sankey diagrams work well for satisfying the following user needs, among others:

- Visualizing how a quantity flows and splits across multiple stages, such as energy distribution;

- Showing holistic and partial hierarchical relationships between sources and destinations;

- Communicating where the largest gains, losses, or concentrations occur within a process.

### Best practices

<p style={{fontSize: '20px',fontWeight: 'bold',}}>Give the diagram room to breathe</p>

Sankey diagrams become hard to read when too many links overlap. Space nodes apart and arrange them so related flows stay close together, helping users trace a path from source to destination.

<ImageGrid
    images={[SankeyBpFlow, SankeyBpCramped]}
    captionsUnderImages={[
        'DO:Spacing nodes apart keeps links readable and easy to trace',
        'DONT:Cramming the diagram into a narrow space makes links overlap and unreadable'
    ]}
/>

<p style={{fontSize: '20px',fontWeight: 'bold',}}>Annotate values for precision</p>

Because the link width only communicates relative magnitude, label nodes and flows with their values when users need to read exact figures. Keep the contrast high and the units consistent across the diagram.

<ImageGrid
    images={[SankeyBpAnnotation, SankeyBpFaint]}
    captionsUnderImages={[
        'DO:Annotate nodes and links so users can read exact values, not just proportions',
        'DONT:Low-contrast or missing labels force users to guess the numbers'
    ]}
/>

<p style={{fontSize: '20px',fontWeight: 'bold',}}>Use hover states to reveal detail</p>

For dense diagrams, reserve secondary detail such as consumption breakdowns or footprints for hover interactions. This keeps the default view clean while still letting users explore individual flows on demand.
